# Fake News Detection using Machine Learning

A machine learning project that detects fake news using TF-IDF and Logistic Regression with the WELFake dataset.

## Features
- Text preprocessing
- TF-IDF vectorization
- Logistic Regression classification
- Model evaluation and prediction

## Results
- **Accuracy:** 95.39%
- **Dataset:** WELFake
- **Language:** Python

## Technologies
Python, Pandas, Scikit-learn, NLP

## Run the Project
```bash
pip install -r requirements.txt
python src/train_model.py
```
